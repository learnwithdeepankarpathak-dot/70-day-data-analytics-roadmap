# 70-Day Data Analytics Roadmap

**Don't run. Just don't stop.**

A free, day-by-day roadmap to go from zero to job-ready in data analytics in 70 days, with 1 to 2 hours a day.
Every day tells you what to learn, gives you a free resource and a task, and asks one interview question.

## How to use it

**The daily routine**
1. Learn the topic from the main resource (20 to 30 minutes).
2. Do the task under "Do today" (40 to 60 minutes). This is where you actually learn.
3. Answer the interview question aloud, as if a recruiter asked it.
4. Save your work in one folder. It becomes your portfolio.

**The rules**
- Slow is fine. Stopping is not.
- Busy or tired? Do the 20-minute minimum: one interview question and one small task. The streak stays alive.
- Never miss twice. Missing one day is life; missing two in a row is the start of quitting.
- Every 7th day is a Review and Catch-up day. Use it to fix gaps, not to rest.

**What you need**
- A Windows laptop (SSMS and Power BI Desktop are Windows only)
- Microsoft 365 or Excel 2024 (older Excel has no XLOOKUP, FILTER or TEXTSPLIT)
- SQL Server Developer edition and Power BI Desktop, both free
